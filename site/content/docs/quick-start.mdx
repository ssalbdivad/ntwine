## Requirements

- **Node 22.13 or later.**
- **A Claude Code or Codex subscription you're signed in to.** Ntwine drives the subscription you already pay for. It brings its own pinned copy of each CLI, downloaded once on first start, so the version on your PATH never changes what a thread runs.
- Optionally, any [ACP agent](/docs/agents#acp-agents) on your PATH: OpenCode, Gemini CLI, GitHub Copilot CLI, Cursor's agent, goose, Qwen Code and more.

Ntwine runs on macOS, Linux and Windows. It doesn't care how you do version control, and it doesn't need Git.

<Steps>

<Step>

### Run it in a project

```bash
cd path/to/acme
npx ntwine
```

```text
  NTWINE v0.4.0  ready in 4.0s

  ➜  Local:    http://127.0.0.1:9393/
  ➜  Project:  acme — path/to/acme

  press ctrl-c to stop · run with --debug for the full event feed
```

A browser tab opens on All projects. Ntwine listens on port 9393 (19393 if something else holds it). The first time, it asks whether to add the repository as a [project](/docs/projects). Running the command never adds one by itself.

The first time a browser opens Ntwine, it lands on All projects and a short tour points out the project switcher, the prompt box, the queue and the thread list. **Take the tour** in <kbd>⌘</kbd><kbd>K</kbd> replays it.

</Step>

<Step>

### Start a thread

Type a task in the prompt box and press <kbd>Enter</kbd>. You can pick the agent, model and effort beside the box. If you leave effort on **auto**, a quick model picks it for each prompt.

</Step>

<Step>

### Answer when it asks

The agent works on its own until it reaches something only you can settle. Then its thread becomes a card in the queue, usually with a [question](/docs/questions) you can answer in one keystroke. From there you can reply, [snooze](/docs/snooze) it, or mark it done with <kbd>d</kbd>.

</Step>

<Step>

### Add another project

Run `npx ntwine` in a second repo. It joins the server that's already running and asks whether to add the repo. Once you confirm, its board opens. The switcher above the prompt box moves between projects, and its first choice, **All projects**, shows every project at once.

</Step>

</Steps>

## Prefer your editor?

The [VS Code extension](/docs/editor) puts Ntwine beside your code.

## Try it without touching your setup

```bash
npx ntwine --sandbox
```

This starts a disposable Ntwine with a throwaway home and project on its own port, and deletes it when the terminal closes. Your credentials come along, so it sees what your real board sees.
