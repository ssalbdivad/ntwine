## VS Code, Cursor and Windsurf

The ntwine extension puts the real ntwine page in your editor's sidebar, in your colour theme, on that window's project. You get the same queue, cards, prompt boxes and shortcuts.

- **What you select goes with your message.** A bar over the prompt box names the file in front and your selection (`sample.ts:12-20`), and sends it with your next message. "Why does this throw?" needs no pasting. For files that may hold secrets, only the line numbers are sent, never the text.
- **Agents can see your editor.** An agent can read what's in front of you, even when you talk to it in a browser: the file, your selection, your open tabs, and the editor's errors and warnings. The eye on the bar turns all of it off.
- **<kbd>Ctrl</kbd><kbd>L</kbd> (<kbd>⌘</kbd><kbd>L</kbd> on macOS) adds code to a prompt**, the same chord as Cursor. <kbd>Alt</kbd><kbd>K</kbd> works too, as in Claude Code.
- **Review a thread's changes** as the editor's multi-file diff, from the thread's <kbd>⋯</kbd> menu or its list of edited files.
- **File links open in the editor** at the line they name, in the window that has the project open.
- **Open a thread in an editor tab**, beside the code.

Install it from the [extension's README](https://github.com/ssalbdivad/ntwine/blob/main/packages/vscode/README.md). Without it, file links can still open in `$VISUAL`/`$EDITOR` or another app of your choice, which you can set under **Settings**.

## Files and pictures in ntwine

Code and text files open in ntwine's own reader, which follows the file as it's saved. Pictures and videos open in a viewer you can zoom and page through. When an agent wants to show you screenshots or a recording, it puts them in a gallery on its message.
