  Serving https://mk7w2qp9x4n3f6tbz5vh.frizz.sh (frizz.sh).

Your board stays on loopback and **dials out** to frizz.sh. That one fact removes the inbound port, the tunnel binary and the DNS record all at once, so a laptop behind any NAT works with no configuration. The connection comes back by itself after a sleep or a network change, so a board is reachable again as soon as the machine is.

## A private name

The default. Ntwine mints an unguessable name — 20 random characters, so nobody finds it by guessing — and claims it with this machine's own key. No sign-in of any kind.

The name is the address, not the lock: the first visit from every device still needs a single-use [sign-in link](/docs/remote-access#ntwine-does-the-authenticating).

## Custom names are paused

A name you choose, such as `ada.frizz.sh`, is tied to a GitHub account, and that sign-in is not set up yet, so Ntwine does not offer one for now. A board that already holds one keeps it: every renewal is signed by this machine's key and needs no GitHub sign-in.

## Keeping a name

Your machine holds an Ed25519 key, `identity.key` in Ntwine's state directory (`~/.ntwine/` on an install that has one), and that key alone proves ownership. Renewals need no sign-in. Ownership moves between machines the way an SSH key does: copy the file.

Every launch renews the lease. A name nobody has run for **30 days** is released.

## What you are agreeing to

- **One name per machine key.**
- **The name is a lease, not property.** It lapses after 30 days unused, and Ntwine can reclaim any name at any time — that is the only enforcement there is, so it has to exist.
- **Your traffic passes through us.** A name on frizz.sh is served by a relay we run: every request and every keystroke goes through it. Ntwine's own access gate still runs on your machine, so a visitor meets it whether or not the relay is honest — but if you would rather no third party carried the bytes, use [a domain you control](/docs/cloudflare-tunnel).
- **No warranty.** This is a free convenience on a domain someone else owns. Anything you cannot afford to lose access to belongs on a domain you control.
