title: Questions
description: When an agent needs you, it asks a question you can answer in one keystroke.
---

When a worker hits something only you can settle, it asks a question with numbered options. Each option says what picking it means, and the worker marks the one it would choose as **recommended**. Most of the time, answering takes a single keystroke.

<Shot src="/img/question.png" width={1600} height={558} alt="A question card asking whether the settings store should use SQLite or a JSON file, with option A marked recommended, a row for typing something else, and below it a countdown to the recommended pick." />

There's always a row for writing something else instead. A typed reply leaves the questions open. The agent is told which ones still are, and withdraws any it no longer needs.

## Several at once

When the answer isn't just one thing, a card can take several. Check any combination and add a note. A question can also carry follow-ups that only appear for the option you pick, so you're never asked "and which one?" after you've said no.

## Nothing stalls on you

A question you leave alone doesn't hold up the thread forever. Ten minutes after the agent comes to rest on it, ntwine answers with the recommended option. A countdown under the card shows when, and its <kbd>×</kbd> turns it off for that question. A question you've typed a reply past waits for you.

An option that acts outside your machine, like posting a comment, merging, publishing or spending money, is never picked for you. If every option does, the question waits.

## Steps

Sometimes the agent needs you to do something it can't, like signing in, approving a prompt or pressing a button it isn't allowed to press. In that case the card lists numbered steps and a **Done** button, which tells the agent you've finished. If a step didn't work, reply instead.

## On a phone

Simple questions take one tap on the card. Larger ones open in a sheet, one step at a time. See [phone](/docs/phone).
