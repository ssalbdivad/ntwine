Ntwine runs your coding agents from one browser tab. That includes Claude Code, Codex, and any agent that speaks the Agent Client Protocol. When an agent comes to rest needing you, it becomes a card in a single queue, so you can work through a list instead of checking on ten terminals.

```bash
npx ntwine
```

Ntwine doesn't bring a model or a workflow of its own. It drives the CLIs you already pay for under your sign-in, and every opinion it has lives in a text file you can edit.

## What it does

<Cards>
  <Card title="One queue" href="/docs/queue">
    An agent that needs you becomes a card. Answer it, steer it, snooze it, or mark it done.
  </Card>
  <Card title="Answerable questions" href="/docs/questions">
    Agents ask with numbered options and a recommendation. One keystroke answers.

  <Card title="A board per project" href="/docs/projects">
    One server serves every repo on your machine. Each has its own board, and All projects is a click away.
  </Card>
  <Card title="Headless" href="/docs/threads">
    Each agent runs in its own background process. Close the tab or stop Ntwine, and it keeps working.
  </Card>
  <Card title="Threads that talk" href="/docs/handles">
    Every thread has an `@handle`. Agents read, message and wait on each other by it.
  </Card>
  <Card title="Schedules and time limits" href="/docs/schedules">
    "Every weekday at 9am" starts a fresh thread each time. "2h" bounds one.
  </Card>
  <Card title="Your editor" href="/docs/editor">
    Ntwine in VS Code, Cursor or Windsurf, with your selection sent along.
  </Card>
  <Card title="From anywhere" href="/docs/remote-access">
    Reach Ntwine from your phone with a private frizz.sh name, a tunnel, or Tailscale.
  </Card>
</Cards>

## What it is not

- It's not a model. Ntwine drives the CLIs you already have signed in, on your subscription.
- It's not a cloud. There's no account and no telemetry. The server binds `127.0.0.1`, and its state lives in your user directory, never in your checkout.
- It's not a workflow. No worktrees, branches or build steps happen behind your back, and a thread behaves like a session you started yourself.
